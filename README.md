# My Manager

A Flutter application designed to help users manage transaction records and export financial reports in convenient formats.

## Features

- **Transaction Management** — Work with transaction records.
- **CSV Export** — Export transaction data as CSV files.
- **PDF Reports** — Generate PDF reports from transaction data.
- **Download Reports** — Save exported reports to the device.
- **Share Reports** — Share CSV and PDF files with other applications.

## Built With

- Flutter
- Dart
- PDF generation package
- CSV file handling
- Device file saving and sharing packages

## Getting Started

### Prerequisites

Before running this project, make sure you have installed:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio or Visual Studio Code
- An Android device or emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/moslah59/my_manager.git
   ```

2. Navigate to the project directory:

   ```bash
   cd my_manager
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
